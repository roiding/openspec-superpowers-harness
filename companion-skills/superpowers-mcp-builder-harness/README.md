# Superpowers MCP Builder Harness

This companion skill is for MCP server work.

## Use this when

- designing a new MCP server
- adding MCP tools, resources, or prompts
- improving MCP input validation or error handling
- testing and hardening MCP protocol behavior
- preparing an MCP server for release or distribution

## Do not use this when

- the task is ordinary app development with no MCP surface
- the main delivery skill already covers the task completely

## Example prompts

- `Use superpowers-mcp-builder-harness to design a new MCP server for our internal issue tracker.`
- `Use superpowers-mcp-builder-harness to add a safe delete tool and validate its error handling.`
- `Use superpowers-mcp-builder-harness to review whether this capability should be a Tool, Resource, or Prompt.`
- `Use superpowers-mcp-builder-harness to harden this MCP server before release.`
