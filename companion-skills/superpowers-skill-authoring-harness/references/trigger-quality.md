# Trigger Quality

Use this reference when writing `name` and `description` in skill frontmatter.

## Description rule

Describe when to use the skill, not the full workflow inside it.

## Include

- triggering scenarios
- symptoms
- concrete context
- likely search phrases

## Avoid

- giant workflow summaries
- vague phrases like "for many tasks"
- narrative history
- scope so broad that many unrelated tasks would trigger it
