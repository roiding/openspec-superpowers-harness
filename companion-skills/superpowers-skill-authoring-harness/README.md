# Superpowers Skill Authoring Harness

This companion skill is for creating or revising skills themselves.

## Use this when

- creating a new Codex skill
- splitting a large skill into companion skills
- revising skill triggers and frontmatter
- validating whether a skill is too broad or too vague
- applying a documentation-TDD loop to skill authoring

## Do not use this when

- you only need normal project delivery
- you are writing repo docs rather than skill docs

## Example prompts

- `Use superpowers-skill-authoring-harness to create a new Codex skill for our deployment workflow.`
- `Use superpowers-skill-authoring-harness to refactor this skill because its trigger description is too broad.`
- `Use superpowers-skill-authoring-harness to split this oversized skill into a main skill plus companions.`
- `Use superpowers-skill-authoring-harness to review whether this SKILL.md is actually reusable enough to justify a new skill.`
