# OpenSpec Workspace Customization

This companion skill handles the OpenSpec capabilities that are broader than normal single-repo feature delivery.

## Use this when

- planning spans multiple repos or folders
- you need OpenSpec workspace coordination
- you want to customize `openspec/config.yaml`
- you need a custom schema or workflow
- you need to reason about OpenSpec tool/delivery mapping

## Do not use this when

- you just want to build a normal feature in one repo
- the main `openspec-superpowers-harness` skill is already sufficient

## Example prompts

- `Use openspec-workspace-customization to help me design a multi-repo OpenSpec workspace for api, web, and worker repos.`
- `Use openspec-workspace-customization to decide whether this project should stay repo-local or move to an OpenSpec workspace.`
- `Use openspec-workspace-customization to customize our OpenSpec schema so review happens before tasks.`
- `Use openspec-workspace-customization to tune openspec/config.yaml for our TypeScript monorepo.`
