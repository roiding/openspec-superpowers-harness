# Companion Skills

This directory contains optional companion skills that were intentionally not folded into the main `openspec-superpowers-harness` skill.

## Included companions

- `openspec-workspace-customization`
- `superpowers-mcp-builder-harness`
- `superpowers-skill-authoring-harness`

## Why they are separate

They are useful, but too specialized to load by default for normal project delivery.

## Installation note

Nested skill folders inside this repository are **not** auto-discovered just because the main skill is installed.

To use one of these companions, copy or symlink the specific companion folder into your Codex skills directory as its own skill folder.
